title: Getting started with Orincard
description: Create, edit, save, export, and recover your first carousel safely.
---

## Choose an input

Start with a topic or paste text. Signed-in accounts can also use a public URL or upload a PDF, slide deck, or video. Review extracted content before generation because source quality affects the draft.

## Review and save

Generation creates an editable candidate. Check every slide, source claim, image right, caption, and Brand Kit choice before saving. Saving creates an account-owned project version so later edits do not replace earlier snapshots.

## Export

Run preflight before requesting PNG, JPG, PDF, PPTX, MP4, or caption output. Fix blocked fonts, overflowing text, missing assets, and unaccepted generated images. Finished downloads expire, but the saved project version remains available.

## Restore a project

Inspect a supported recovery ZIP or PDF attachment before confirming import. Orincard reports missing assets first, then creates new project, version, asset IDs, and private object keys for the restored copy.

## Manage billing

Checkout and billing management use the hosted payment provider. A cancellation scheduled for the end of the paid period does not delete projects. Account deletion is a separate confirmed operation in Settings.

## A safe first workflow

1. Create a short draft from a topic.
2. Review the generated slides and caption.
3. Save the project and check its version history.
4. Run export preflight and download one format.
5. Keep a recovery-enabled export when you need a portable backup.
