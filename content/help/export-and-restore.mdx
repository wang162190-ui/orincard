---
title: Export and restore projects
description: Choose an output, resolve preflight issues, and keep a portable recovery copy.
---

## Run preflight first

Resolve overflowing text, missing fonts, unavailable assets, and unaccepted generated images before export. A successful preflight applies to the current project revision only.

## Choose the right output

- PNG or JPG works for page-by-page publishing.
- PDF keeps the sequence together.
- PPTX keeps supported text editable.
- MP4 turns the ordered pages into a video.

## Restore without overwriting

Inspect a supported ZIP or recovery-enabled PDF before confirmation. Restore creates a new project, version, asset IDs, and private object keys. The source project remains unchanged.

## Handle an expired download

Generated download links expire. Request the format again from the saved project instead of sharing a private object URL.
