# 来源、任务、渲染与失败恢复

> source: docs/sdd/orincard/spec.md

2026-09-04。实现必须使用明确状态和可测结果。

## 1. 输入限额与安全（AC-002）

技术默认：Topic500字符，Text30000字符；页数4–12/默认6；开发文件<=50MiB（Supabase项目若配置更小则从其限制），生产配置未经审批不提高；PDF/PPTX<=100页；扫描OCR最多20页；Video<=30分钟。每个限制在提交/上传前显示并在服务端再次验证。超限不悄悄截断，允许用户缩小来源。生产大视频支持上限通过配置和压测后开放，不把50MiB误当无限分块。

URL只允许http/https标准端口，无userinfo；DNS A/AAAA全部检查、连接固定到已检查IP，拒绝回环/私网/link-local/metadata/IPv4映射IPv6；每跳重定向重新检查，最多5跳。限制正文10MiB、30秒、允许MIME、robots/访问限制；登录墙/空正文给粘贴文本替代。不将用户指定headers/cookies带到抓取。截图独立隔离浏览器网络，子资源/WebSocket/重定向同样阻止内网访问，不能只检查导航URL。

文本提取和页面脚本分离：Readability在无网络、无脚本执行的DOM环境运行，清洗HTML后只保留正文。PDF.js提取文字并保持页码；文字为空时先检测扫描页，OCR经用户提示和预算检查后逐页执行，不将“无文本层”当空白轮播。PPTX用ZIP/XML提取文字/顺序/选定图片，禁止外部实体、外链和宏；不是复刻原PPT全部版式。

视频来源仅用户有权提供且可合法读取的文件/字幕/直链；不承诺任意YouTube URL。FFmpeg抽音轨、按转录API大小上限切段，保留真实时间偏移。无字幕/权限/过期URL时提示重新上传或粘贴文字稿；从未转录过的片段不能生成事实。

ZIP/PPTX/PDF附件导入限制：解压总量<=250MiB、文件数<=1000、压缩比<=100；路径规范化，拒绝绝对路径、`..`、符号链接、可执行文件、外部引用、重复冲突路径；PDF附件只接受明确的Orincard恢复包，不运行PDF脚本。生产提高限制要重跑资源测试。

## 2. 任务协议（AC-002/003/006/009）

`pending_dispatch → queued → running → succeeded | partial | failed | canceled`。stage为validate/parse/transcribe/outline/write/layout/render/package/upload；不支持的阶段不伪造进度。进度以已完成单位计，任务完成须先校验上传对象及业务事务提交。

Trigger载荷仅jobId、schemaVersion和requestId；正文/图片从授权来源读取。worker自查owner、输入引用、项目状态及budget reservation。云端开发使用已部署的开发任务，不让`trigger dev`把工作拉回本机。

任务重试最多3次，指数退避加抖动；输入错误不重试；提交外部AI后不确定状态不盲目多次发起。提供商返回操作ID则查询后恢复，没有可查询ID则记录未知成本并按预算受控重试。应用保证业务幂等，不谎称供应商绝对不会重复收费。

reconciler每5分钟检查pending_dispatch、过期心跳、取消请求和未结算预留，查询云任务状态后修复。平台故障保留可恢复任务，不因心跳慢就重复提交新job。取消是请求，阶段边界/终态回写均检查取消或删除标记；不在删除后重建项目/下载链接。

取消写入cancel_requested_at并与终态事务锁竞争；先取消则不交付结果且释放产品额度，先成功则返回既有结果状态。每次worker attempt带lease_token，旧worker不得覆盖新尝试。预算通过cost_reservations和cost_attempts按请求/调用追溯；未知供应商结果继续占用保守预留，崩溃重启或跨月不能直接归零。幂等保证用户产品账不双扣，但不隐瞒供应商重复执行成本。

多格式导出是父级协调和独立子job；仅失败格式重试；已完成的格式/人工编辑保留。外部成本照实记录，用户产品额度只结算已交付任务定义的成功单位；失败释放，部分成功展示已结算/已释放明细。

## 3. 生成与来源约束（AC-003/010）

抽取/结构与文案生成分步；以Zod解析JSON，不信任模型返回的HTML或资源URL。schema错误最多一次有界修复，仍失败保留输入状态并释放额度。用户原文属于数据，不执行其中“忽略系统指令/泄露密钥”等指令。模型不接触服务密钥、跨项目内容或付款权限。

生成参数language/contentFormat/pageCount/instructions/template/platform纳入requestHash。引用需逐字匹配可用来源，非引用内容不标为原话。输入时间码缺失则为空。Topic知识生成需标为AI草稿、不捏造明确引用作者。重新生成和七工具产物都是候选，接受后写回；生成前用户已修改的字段必须被版本检查保护。

## 4. 渲染与导出（AC-004/005/006/007）

在worker独立构建可信render entry，以React服务器输出文档组件；Chromium只加载当前任务通过验证的本地素材和固定字体，禁止联网取任意用户URL。截图任务与导出任务的浏览器上下文/缓存隔离。渲染固定viewport/deviceScaleFactor=1，按目标像素输出；字体、图片解码和容器测量完成再截图。

PNG/JPG：一页一文件，检查像素/字节/顺序后打包；PDF使用同一页面几何，处理打印边距为0，检查页数和尺寸。render不同revision不共享未经校验缓存。

PPTX由统一布局测量结果映射文本框、图片和基础形状；至少title/body/CTA保留原生可编辑文本。不承诺与任意Office版本像素相同。字体缺失给兼容性说明；只允许许可支持的字体交付，不默认嵌入系统字体。

MP4默认每页4秒、0.3秒淡入淡出、H.264/AAC、30fps；用户可选每页时长和合法音轨；无音轨可导出无声视频，不自动下载音乐。ffprobe验证尺寸/时长/编码/完整结尾。功能不包括任意视频剪辑或数字人。

资源控制：普通AI/解析任务1GiB，Chromium/OCR2GiB，FFmpeg4GiB作为起始配置；逐页处理、释放解码图片，临时空间设上限。内存不足显式失败，不静默降清晰度。最终峰值内存/耗时以B01和视觉矩阵测量为准。

## 5. 权利、删除与数据导出

Pexels响应保留作者/来源/许可，遵守API缓存和归因要求；用户上传有权利确认。AI图/Portrait必须经用户接受；只处理用户有权使用的人像，不声称任何人像都有商业授权。品牌/模板字体单独许可审计。

删除project先置deleting，RLS禁止读取导出和项目绑定资源；个人素材库中仍被其他活项目引用的素材保留，并明确解释。每个artifact拥有唯一对象key。cleanup只删除引用计数为零且没有活任务持有的资源；清理失败记录重试，不反向恢复project。

用户账号导出JSON+本人允许下载的文件，排除内部日志、所有密钥、支付凭证和其他账户；审计流水仅提供用户相关安全摘要。数据导出与品牌导出、项目恢复是三种不同用途，不混淆。
