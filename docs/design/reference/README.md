## 迁移要求

保持纸色背景、深色侧栏、粉/黄/蓝状态块、标题层级、留白、原始纸鹤标记和三栏编辑结构。复用 CSS tokens 与布局，不用组件库主题覆盖。

当前 CSS 使用系统字体；生产改为经过许可验证的自托管字体。版式相近优先，未通过比对不得声称像素完全一致。字体二进制不随本次参考包增加。

## 明确修正的模拟行为

1. 不采纳“未编辑前无限免费重新生成”；同一请求重试幂等，新请求按权益计量。
2. 文字溢出阻断 PNG/JPG/PDF/PPTX/MP4，不保留 PNG 绕过路径。
3. `.key` 需转 PPTX；扫描 PDF 有受限 OCR，不把空提取当作成功。
4. 跨页状态、云端保存、版本、下载必须真实联通，不用 toast 替代。
5. 平台尺寸来自所选生成器：LinkedIn/Instagram 1080×1350，TikTok 1080×1920；页数 4–12、默认 6。

## 素材权利

`assets/img/credits.json` 记录了部分照片的作者、CC BY 2.0 声明和来源链接。这是随设计提供的来源记录，不等于已独立核验版权、肖像或商业使用条件。未在 credits 中列明的图片一律标为未验证。全部照片只作为私有设计参考；上线前完成许可审计或替换。原图、品牌包、用户头像不得作为公共图库自动开放。

`manifest.json` 保存此快照每个文件的 SHA-256。文档检查会校验文件未变更以及本地资源引用不缺失；不会执行设计页面里的脚本，也不会把哈希检查当视觉验收。
