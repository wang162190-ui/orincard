Orincard · AI Carousel Creator

A working prototype of the create → edit → keep loop

Three product areas from the spec, built as real screens with working state rather than static mockups. The interface is in English because the spec sets English-first UI and output. Start at the generator and follow the flow, or open any screen directly.

Step 1

AI Generator

AC-001 · AC-002
  • Six source tabs — Topic, Text, URL, Video, PDF, Slides — each with its own input and limits.
  • Platform preset changes the canvas size and the preview ratio live.
  • URL validation rejects private addresses, credentials in the address and unsupported file types, each with its own reason.
  • The PDF tab holds one parsed file and one that genuinely failed, with a specific repair action.

Step 2

Carousel Editor

AC-003 → AC-006
  • All four page modes render for real: text, text + image, full-bleed image, screenshot.
  • Text fit resizes the body type and moves the capacity threshold with it, so Roomy can push a slide over the limit and Tight can pull it back.
  • Slide 4 starts over capacity, so export preflight stops PDF, PPTX and MP4 while PNG and captions still run. Shorten it and all five clear.
  • The AI writing assistant proposes a change to one field and waits for accept or reject.
  • Regenerate rewrites only the slides you have not locked. Slides you wrote yourself are never touched, the button counts the real total, and one Undo brings the old draft back.
  • Every image carries its licence and author; one you upload yourself is labelled as yours.

Step 3

Project library

AC-007
  • Search, platform and status filters, sorting, grid and list views.
  • Version history restores into a new version instead of overwriting.
  • Import shows the manifest, what will be restored and what cannot be — before anything is created.
  • A damaged package is refused with the actual reason, not a generic error.

Alongside

Brand Kits

AC-008
  • Signature, name, website, CTA, palette, accent, type and page-number defaults — all bound to a live preview.
  • Create, duplicate and rename; a duplicate starts applied to nothing.
  • Deleting a kit that is in use requires an explicit decision per project — replace with another kit, or keep today's look as the project's own styles.

Left blank on purpose

Spec section 11 marks these as unresolved. Nothing in the prototype invents a number for them.

  • Prices, quotas, page limits and which plan unlocks high-resolution, PPTX or MP4 — the generator says only that drafts stay local until you sign in.
  • Payment entity, tax regions, refund window and affiliate commission.
  • Licences and regional availability for the stock library, AI image, transcription and music providers.
  • Trademark, domain, privacy policy and the user-content rights statement.

Notes on the build

Original Every template, layout, icon and line of copy here is original. No competitor's brand, templates, assets or interface was copied, and nothing behind a login or paywall was accessed.
Photography Six photographs by Shixart1985, CC BY 2.0 via Wikimedia Commons, resized locally. Full attribution is in assets/img/credits.json and repeated in the editor, under every image in the Content tab.
Slide rendering One .slide component drives the filmstrip thumbnail, the editor canvas, the library covers and the Brand Kit preview. It scales with container queries, so a 46-pixel thumbnail and a full canvas use identical markup.
State Screens hold their own state and reset on reload. Navigation between them is by link, so a change made in the editor is not carried into the library.
Content The demo carousel argues a point about meetings. It contains no statistics, benchmarks or claims of fact, because none were available to cite.
